# Visto — assinatura de produto

Identidade do produto de rotina operacional da HAWKS BI. O check bicolor, com construção angular, forma o **V** de Visto: o preto sustenta a operação e o laranja oficial (`#FF7900`) sinaliza confirmação.

## Arquivos

| Arquivo | Uso |
| --- | --- |
| `visto-wordmark.svg` | Assinatura principal sobre papel e superfícies claras |
| `visto-wordmark-reverse.svg` | Assinatura principal sobre superfícies escuras |
| `visto-wordmark-on-orange.svg` | Assinatura para superfícies laranja |
| `visto-mark.svg` | Ícone compacto com cor sobre superfícies claras |
| `visto-mark-reverse.svg` | Ícone compacto com cor sobre superfícies escuras |
| `visto-mark-on-orange.svg` | Ícone compacto para superfícies laranja |
| `visto-mark-mono-ink.svg` | Aplicação técnica monocromática sobre fundo claro |
| `visto-mark-mono-paper.svg` | Aplicação técnica monocromática sobre fundo escuro |
| `visto-favicon.svg` | V isolado, em quadrado preto, para aba do navegador e atalhos |

## Uso

- Prefira a assinatura completa quando o produto ainda precisar ser identificado.
- Use apenas o mark quando o contexto já mostrar o nome Visto ou o espaço for compacto.
- Mantenha uma área livre de, no mínimo, 25% da altura do mark.
- Sobre papel, branco e tons claros, use `visto-wordmark.svg` e `visto-mark.svg`.
- Sobre `#080808` e tons escuros, use `visto-wordmark-reverse.svg` e `visto-mark-reverse.svg`.
- Sobre `#F2610A` ou `#FF7900`, use as versões `-on-orange`; o traço ascendente muda para papel para não desaparecer.
- Em impressão de uma cor, use `visto-mark-mono-ink.svg` no claro ou `visto-mark-mono-paper.svg` no escuro.
- O arquivo preserva a tipografia Instrument Sans usada na interface. Para uma peça offline, mantenha a fonte instalada ou converta o texto em curvas no editor de destino.
